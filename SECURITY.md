# Security Policy

## Supported Versions

We provide security updates and patches for the following versions of **Clinical-Virtual-Health-Platform**:

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The maintainers of **Clinical-Virtual-Health-Platform** take cybersecurity and vulnerability management seriously. If you discover a potential security vulnerability (e.g., sandbox escape, SSRF, injection, authorization bypass, or crypto tampering), please follow these steps:

1. **Do NOT open a public GitHub issue.**
2. Send an email to **codesphereinnovationz@gmail.com** with:
   - Repository name: `Clinical-Virtual-Health-Platform`
   - Summary and type of vulnerability
   - Step-by-step reproduction instructions or proof-of-concept
   - Potential impact on systems or data integrity
3. We will acknowledge receipt within **48 hours** and provide a timeline for triage and resolution.
4. Once a fix is verified, a patched release and coordinated security advisory will be published.

## Safe Harbor & Attribution

We appreciate responsible security research. If you make a good-faith effort to avoid privacy violations, data destruction, and service interruption during your research, we will not pursue legal action against you and will gladly credit you in release notes.
